## 📂 Projects

### 1. 🎓 Student Course Database

This project focuses on creating and working with a **Student Course Database** using MySQL.

**Database:** `student_course_db`

**Table:** `students`

**Operations Covered:**

* Create Database
* Use Database
* Create Table
* Primary Key
* Unique Constraint
* Not Null Constraint
* Insert Student Records
* Show Tables
* Select All Records
* Select Specific Columns
* Sort Records using `ORDER BY`
* Filter Records using `WHERE`
* Use `NOT` conditions

The project includes student information such as student ID, name, email, phone number, course name, date of birth, and registration date.

---

**Key Areas:**

* Database management
* Table creation
* Data insertion
* Data retrieval
* Column selection
* Record sorting
* Conditional filtering
* Working with date and datetime values

The SQL work demonstrates retrieving complete records, selecting particular columns, sorting students by name and registration date, and filtering students based on their course.
